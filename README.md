# Simple Shell in Rust
Simple Shell which is written in Rust, with built in functions: help, cd and exit.
Only works on Linux.
cd currently does not work.

## How to run
Run
```
git clone git@github.com:Sebas2432/shellProject.git
cd shellProject
cargo run
```

Just a simple shell, with currently no cursor movement or command history.
Can run most commands which are already installed.
